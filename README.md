# ATM Machine Simulation

A basic browser-based ATM simulation built using HTML, CSS, and vanilla JavaScript. This project was developed during my front-end development training at Mastery Hub Rwanda in August 2026.

## Features

- PIN verification
- Cash deposits
- Cash withdrawals
- Balance inquiries
- Insufficient balance detection
- Persistent balance using localStorage
- Login session persistence
- Logout functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Storage API (localStorage)

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Enter the demo PIN: `1234`.
4. Use the ATM dashboard to perform transactions.

## Concepts Practiced

- DOM manipulation
- Event listeners
- Conditional statements
- JavaScript functions
- Browser local storage
- Basic transaction logic

## Disclaimer

This project is an educational simulation. It uses a hardcoded PIN and browser localStorage and is not intended for real financial transactions or secure authentication.
